# ResQMe - Intelligent Cyber-Physical Emergency Response System

This is a React Native application for the ResQMe project.

## Features

- **Crisis Support:** AI-driven chat interface for emergency assistance.
- **Medical ID:** Comprehensive medical profile with auto-transmit capabilities.
- **Tactile Tracking:** Real-time path tracking and navigation.
- **Safety Settings:** User profile and safety configuration.

## Setup

1.  Install dependencies:
    ```bash
    npm install
    ```

2.  Start the app:
    ```bash
    npx expo start
    ```

## Architecture

- **React Native** with **Expo**
- **NativeWind (Tailwind CSS)** for styling
- **React Navigation** for routing
- **Lucide React Native** for icons

## Screens

- **Crisis Support (Home):** Chat with ResQMe AI.
- **Medical ID:** View and manage medical information.
- **Tracking:** View tactile path and controls.
- **Settings:** Manage safety preferences and contacts.
